# ADIF 通联日志统计图

读取 ADI/ADIF 文件，在本地生成 365 天每日 QSO 热力图及近 12 周波段占比堆叠图。不上传日志。

## 快速运行

需要 Python 3.10 或以上。当前机器已安装项目本地依赖，可在此目录运行：

```powershell
py -3.11 plot_qso.py "lotwreport (1).adi"
```

新机器推荐创建虚拟环境：

```powershell
py -3.11 -m venv .venv
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
.\.venv\Scripts\python.exe plot_qso.py "lotwreport (1).adi"
```

macOS / Linux 使用 `python3 -m venv .venv`，然后使用 `.venv/bin/python` 安装依赖及运行程序。仅首次安装依赖需要联网。

`.python_deps` 是本次安装的本地依赖目录，存在时优先使用；更换机器或 Python 版本时不要复制它，请重新安装依赖。

## 在配置文件中选择倒推日期

修改程序旁的 `config.json`：

```json
{
  "end_date": "2026-10-27"
}
```

`end_date` 是统计截止日，日期使用 UTC，包含当天：

- 第一张：从截止日减 364 天到截止日，共 365 天。
- 第二张：以截止日期所在 UTC 自然周的上一周周日为终点，倒推 12 个完整自然周（84 天）。每周为周一 00:00 至下周一 00:00（不含），采用 ISO 周编号。当前周始终排除，即使截止日期是周日，也不计入尚未结束的这一周。
- 设为 `null`，会自动使用日志中最新的通联日期。
- 优先级：命令行 `--end-date` > 配置 `end_date` > 日志最新日期。

例如配置日期为 `2026-10-27`，每日窗口为 **2025-10-28 至 2026-10-27**，每周窗口为 **2026-08-03 至 2026-10-25**。

```powershell
# 临时覆盖配置日期
py -3.11 plot_qso.py "lotwreport (1).adi" --end-date 2026-12-31

# 使用其他配置或输出目录
py -3.11 plot_qso.py "lotwreport (1).adi" --config "config.json" --output-dir "charts"

# 非 UTF-8 编码日志
py -3.11 plot_qso.py "other.adi" --encoding gb18030
```

默认读取程序所在目录的 `config.json`。自定义配置文件路径、输入路径及输出路径相对于终端当前目录。

## 图片和计数口径

两张图均为 **15 × 5 英寸（3:1）**，PNG 为 **3000 × 1000 像素（200 DPI）**，同时提供 SVG 矢量图。图中文字采用英文，避免跨平台中文字体缺失。

### 每日热力图

- 每个方格是一天，每列一周，周日置顶。
- **0 QSO：纯白填充 + 绿色边框**；统计范围外不画方格。
- 非零日期按 **1–20、21–40、41–60……** 分档，每 20 次 QSO 变换一次颜色，依次沿浅绿 → 深绿 → 浅蓝 → 深蓝 → 浅红 → 深红渐变；图例从 0 标到实际最大单日 QSO 数，最后一档截至该最大值，不设置溢出合并档。
- 色阶根据本次最大日通联量生成，不同日志的绝对颜色可能不同。
- 每日图包含全部波段。读取 `QSO_DATE`，不采用上传时间或 QSL 确认日期，不转换北京时间。

### 近 12 周比例图

- 按 80m、60m、40m、30m、20m、17m、15m、12m、10m 从下向上堆叠。
- 每周波段占比 = 该波段 QSO 数 ÷ 该周上述九个波段的 QSO 总数 × 100%。非空周柱子总高度为 100%。
- 每根柱子上方 `n=` 标注该周参与统计的 QSO 总数，横轴第一行显示 ISO 周编号（例如 Week 31），第二行显示该周起止日期（例如 07/27–08/02）；跨年仍使用 ISO 周编号，JSON 同时记录 iso_year 和 iso_week。
- 没有通联的周留空，标注 `No QSO`，其比例在 JSON 中记录为 `null`，不虚构百分比。
- 范围外波段及缺少 BAND 的记录不会计入百分比分母，其数量在终端及 JSON 中列出。不根据频率猜测波段。
- 两张图的时间跨度及波段范围不同，总数不必相等。

所有以 `<EOR>` 结束的日志记录各计一次，不按呼号去重，不过滤未确认记录。

## 输出

默认写入当前目录下的 `output/`，同名文件会覆盖：

| 文件 | 内容 |
| --- | --- |
| `daily_qso_heatmap.png` / `.svg` | 365 天每日 QSO 热力图 |
| `weekly_qso_by_band.png` / `.svg` | 近 12 周波段百分比堆叠图 |
| `summary.json` | 日期范围、每日数量、每周各波段计数及百分比、排除数量、配色 |

以前生成的 `monthly_qso_by_band.*` 是旧版月度图，新程序不会更新它们；请使用 `weekly_qso_by_band.*`。

## 解析与验证

支持 ADI 文本格式，不支持 ADX/XML。按 `<字段名:长度[:类型]>值` 的内容长度解析，支持大小写混用、一行多个字段、LoTW 附加说明和文件头。非法或缺失 QSO_DATE、截断字段、末条缺少 EOR 会报错，避免静默漏计。

```powershell
py -3.11 -m unittest discover -s tests -v
```

测试包含字段长度和注释、非法输入、365 天窗口边界、波段过滤，以及 12 个自然周的首尾边界、当前周排除，以及跨年的 ISO 第 53 周。
